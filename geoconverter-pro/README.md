# JP-GeoConverter Pro — 日本の測量座標変換を iPhone 1 台で

**JP-GeoConverter Pro**（旧 GeoConverter Pro）は、日本の測量座標変換に特化した iOS アプリです。世界測地系（JGD2000／JGD2011／JGD2024）と東京測地系、平面直角座標系 第 1〜19 系、緯度経度の相互変換に加え、セミダイナミック補正・定常時地殻変動補正、ジオイドモデル（2011／2024）による標高の扱いに対応します。国土地理院が公開するパラメータファイルを内蔵しているので、すべての変換はデバイス内で完結し、インターネット接続は不要です。

## 何ができるか

| やりたいこと | 使う機能 |
| --- | --- |
| 現在地をその場で複数の座標系に変換したい | GPS モード（現在地のリアルタイム変換・最大 15 行の座標系を並べて比較） |
| 図面・台帳の座標値を変換したい | 手動入力モード（10 進度・度分秒・平面直角座標 X/Y からの逆変換） |
| 複数点をまとめて変換したい | CSV 一括変換（Shift-JIS／UTF-8 自動判定、結果はタイムスタンプ付き CSV で保存） |
| 変換後の位置を地図で確かめたい | 地図画面（GPS／CNV／SIM の 3 モード。標準・衛星写真・ハイブリッド） |
| 作業地域でどの補正が効くか知りたい | 補正量ヒートマップ（TKY2JGD・地震補正・ジオイド差分・SemiDyna・pos2jgd） |
| GPS が使えない場所で動作確認したい | シミュレーションモード（47 都道府県庁所在地から選択） |

全機能がオフラインで動きます（地図の表示だけはキャッシュが無いときにオンライン接続が必要です）。対応 OS は iOS 17.0 以降、iPhone 向け（iPad でも動きます）。

## 誰向けか

- 測量士・土地家屋調査士・地質調査技術者
- 公共測量・建設現場で座標変換が必要な方
- 国土地理院データを扱う GIS 担当者・研究者
- 旧測地系の図面の座標を現行測地系に変換したい方

## 対応する測地系・座標系

| 座標系 | 内容 |
| --- | --- |
| WGS84 | GPS の世界標準測地系（1 行目に常時表示） |
| JGD2000 | 世界測地系移行後の日本測地系 |
| JGD2011 | 東日本大震災後の補正を含む測地系 |
| JGD2024 | 日本測地系 2024（2024 年の測地成果改定で導入。基準系） |
| jgd2024b | JGD2024 ＋ 地震変動補正 |
| jgd2024c | JGD2024 ＋ セミダイナミック補正 |
| jgd2024d | JGD2024 ＋ 定常時地殻変動補正 |
| 東京測地系 | 旧日本測地系（2002 年以前） |
| 平面直角座標系 | 第 1〜19 系（現在地から系番号を自動判定する Auto に対応） |
| 緯度経度 | 10 進度（DD）・度分秒（DMS）の両形式で入力・表示 |

> jgd2024b・jgd2024c・jgd2024d は、座標変換エンジン GeoCoreJP の機能名であり、一般的な正式名称ではありません。

アプリが想定する範囲は北緯 20°〜46°・東経 120°〜154°（日本国内・領海内）です。範囲外では平面直角座標系の自動判定が正しく動かないため、手動設定が必要です。

## 補正の要点

### セミダイナミック補正（SemiDyna）
特定の観測期間（元期）を基準にした経年的な地殻変動を補正し、今期の観測座標を元期の座標に合わせます。パラメータは国土地理院が毎年（4 月頃）更新し、アプリには SemiDyna2026 を内蔵しています。補正量は場所によって異なり、ヒートマップで地域差を確認できます。

### 定常時地殻変動補正（pos2jgd）
プレート運動などの恒常的・継続的な変動を補正します。セミダイナミック補正との違いは更新頻度と対象で、こちらは 2 か月ごとに更新されるパラメータ（pos2jgd_202601_ITRF2020 を内蔵）を使います。どちらを使うかは作業目的と元データの基準日で決まります。

### 地震時地殻変動補正（jgdMerge2011／2024）
2003 年以降の地震に伴う座標の変化を補正します。jgdMerge2011 には十勝沖（2003）から東日本大震災（2011）までの 7 地震、jgdMerge2024 には熊本地震（2016）から令和 7 年青森県東方沖地震（2025）までの補正が含まれます。

### ジオイド 2011／2024
GNSS が出す楕円体高を、ジオイド高を差し引いて標高に直します。ジオイドモデル 2011（gsigeo2011）と 2024（JPGEO2024・離島基準面補正を含む）を設定で切り替えられ、2011 と 2024 の差分もヒートマップで見られます。測地成果 2011 と 2024 の高さを混ぜないための切替です。

### 東京測地系 ⇄ JGD2000（TKY2JGD）
旧日本測地系の図面を現行測地系に直すときの変換です。国土地理院の TKY2JGD パラメータを使い、位置によっては数百 m のズレを補正します。

## よくある質問（10 問）

公式 FAQ の要約です。全文は [よくある質問（FAQ）](https://gcpro.y42u.net/2026/05/26/faq/) をご覧ください。

**Q1. 変換結果が他のツールと数 cm〜数十 cm ずれます。**
補正モデルの違いや、楕円体高と標高の扱いの違いによるものです。設定でジオイドモデル（2011／2024）を切り替えて再変換してみてください。東京測地系 ⇄ JGD2000 の変換は TKY2JGD パラメータを使うため、位置によっては数十 cm の差が出ることがあります。

**Q2. セミダイナミック補正（jgd2024c）と定常時地殻変動補正（jgd2024d）はどう違いますか。**
セミダイナミック補正は特定の観測期間を基準とした経年的な地殻変動を補正し、パラメータは毎年更新されます。定常時地殻変動補正はプレート運動などの恒常的な変動を補正し、パラメータは 2 か月ごとに更新されます。どちらを使うかは作業目的と元データの基準日によります。

**Q3. GPS の精度が悪く、現在地がずれます。**
アプリの座標変換精度と GPS の受信精度は独立しています。屋内や高層ビル付近、金属屋根の下では GPS の測位精度が下がります。手動入力モードを使えば GPS に依存せず任意の座標を変換できます。

**Q4. パラメータはいつ更新されますか。**
国土地理院の公開に合わせ、アプリのアップデートでパラメータを更新します。主要パラメータの最終更新日は設定画面のバージョン情報に記載しています。

**Q5. オフラインで使えますか。**
はい。すべての変換計算とパラメータファイルをアプリ内に内蔵しているため、インターネット接続は不要です。地図表示だけは、キャッシュが無いときにオンライン接続が必要です。

**Q6. GeoDiveExa との違いは何ですか。**
GeoDiveExa は RTK-GNSS で地物を高精度に調査するアプリで、その中に座標変換機能を含んでいます。JP-GeoConverter Pro はその座標変換機能を基に、座標の手入力と CSV の一括変換を加えたアプリです。変換方式と補正パラメータの考え方は共通です。

**Q7. 平面直角座標系の系番号を自動で決めてくれますか。**
系番号を Auto にすると、現在地から系番号を自動判定して「Auto(9系)」のように表示します。Auto は現在位置にもっとも近い系の座標原点で判定するため、系の境界付近では正しい系番号にならないことがあります。境界付近では系番号を手動で指定してください。

**Q8. 無料で使える範囲はどこまでですか。**
フリープランでは、現在地と手入力で 1 座標系（WGS84 表示と緯度経度系）の変換を試せます。追加座標系（3 行目以降）・CSV 入力と保存・平面直角座標系の変換はプレミアム機能です。トライアル期間や価格は App Store の製品ページでご確認ください（時期により変わることがあります）。

**Q9. CSV の文字コードや座標の書き方に決まりはありますか。**
文字コードは Shift-JIS と UTF-8 を自動判定します。座標は 10 進度（例: 35.681236）と、度分秒の 3 種類（結合・スペース区切り・記号付き）に対応します。

**Q10. 海外でも使えますか。**
アプリは北緯 20°〜46°・東経 120°〜154° の範囲（日本国内・領海内）を想定しています。範囲外では平面直角座標系の自動判定が正しく動作しないため、手動設定が必要です。
