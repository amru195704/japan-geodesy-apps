# JP-GeoConverter Pro — 対応座標系・補正・内蔵パラメータ一覧

JP-GeoConverter Pro（旧 GeoConverter Pro）が扱う測地系・座標系・補正と、アプリに内蔵している国土地理院のパラメータファイルを 1 枚にまとめた表です。概要と FAQ は [README.md](README.md) を、用語は [用語集](../glossary.md) をご覧ください。

---

## 1. 測地系・座標系

| 座標系 | 内容 | 備考 |
| --- | --- | --- |
| WGS84 | GPS の世界標準測地系 | 変換画面の 1 行目に常時表示 |
| JGD2000 | 世界測地系移行後の日本測地系 | 東京測地系との相互変換に TKY2JGD を使用 |
| JGD2011 | 東日本大震災後の補正を含む測地系 | |
| JGD2024 | 日本測地系 2024（基準系） | ジオイド 2024 と組み合わせて標高を扱う |
| jgd2024b | JGD2024 ＋ 地震変動補正 | jgdMerge2011／2024 を使用 |
| jgd2024c | JGD2024 ＋ セミダイナミック補正 | SemiDyna2026 を使用 |
| jgd2024d | JGD2024 ＋ 定常時地殻変動補正 | pos2jgd を使用 |
| 東京測地系 | 旧日本測地系（2002 年以前） | |
| 平面直角座標系 | 第 1〜19 系 | 系番号の Auto 自動判定に対応（境界付近は手動指定） |

> jgd2024b・jgd2024c・jgd2024d は座標変換エンジン GeoCoreJP の機能名であり、一般的な正式名称ではありません。

## 2. 座標の入力・表示形式

| 形式 | 例 | 備考 |
| --- | --- | --- |
| 緯度経度・10 進度（DD） | 35.681236 | 入力・表示・CSV |
| 緯度経度・度分秒（DMS） | 35° 40' 52.45" | 入力・表示。CSV では結合・スペース区切り・記号付きの 3 種類に対応 |
| 平面直角座標 X/Y（m） | — | 対応測地系と系番号を選んで逆変換 |

## 3. 補正

| 補正 | 内容 | パラメータ | 更新頻度 |
| --- | --- | --- | --- |
| 東京測地系 ⇄ JGD2000 | 旧日本測地系と世界測地系の相互変換 | TKY2JGD | — |
| 地震時地殻変動補正 | 2003 年以降の地震に伴う座標変化の補正 | jgdMerge2011／jgdMerge2024 | 地震ごとに追加 |
| セミダイナミック補正 | 特定の観測期間（元期）を基準とした経年的な地殻変動の補正 | SemiDyna2026 | 毎年（4 月頃） |
| 定常時地殻変動補正 | プレート運動などの恒常的・継続的な変動の補正 | pos2jgd_202601_ITRF2020 | 2 か月ごと |
| 楕円体高 ⇄ 標高 | ジオイド高による高さの換算 | ジオイドモデル 2011／2024（設定で切替） | — |

## 4. 内蔵パラメータファイル

| ファイル | 内容 |
| --- | --- |
| TKY2JGD | 東京測地系 ⇄ JGD2000 変換テーブル |
| gsigeo2011_ver2_2 | 日本のジオイド 2011 |
| JPGEO2024（＋Hrefconv2024） | 日本のジオイド 2024（離島基準面補正を含む） |
| jgdMerge2011 | 2003 年〜2011 年の地震等座標補正データ |
| jgdMerge2024 | 2016 年以降（2025 年 青森県東方沖地震まで）の地震等座標補正データ |
| SemiDyna2026 | セミダイナミック補正パラメータ（毎年更新） |
| pos2jgd_202601_ITRF2020 | 定常時地殻変動補正パラメータ（2 か月ごと更新） |

パラメータはアプリのアップデートで随時更新します。主要パラメータの最終更新日は設定画面のバージョン情報で確認できます。

## 6. 有効範囲・動作環境

| 項目 | 内容 |
| --- | --- |
| 地理的範囲 | 北緯 20°〜46°／東経 120°〜154°（日本国内・領海内）。範囲外では平面直角座標系の自動判定が正しく動作せず、手動設定が必要 |
| 対応 OS | iOS 17.0 以降 |
| デバイス | iPhone（iPad でも動作） |
| インターネット接続 | 不要（全機能オフライン動作。地図表示のみキャッシュが無いときにオンラインが必要） |
| 位置情報 | 任意（手動入力・シミュレーションモードでも変換可） |

## 7. 精度の確かめ方

変換結果は、国土地理院の公式ツール（TKY2JGD・PatchJGD・SemiDynaEXE・POS2JGD）と全テストポイントで比較して検証しています。

- [座標変換を国土地理院の公式ツールで全数検証する](https://gcpro.y42u.net/2026/06/17/gsi-coordinate-validation/)
- [全テストポイントを国土地理院の変換サイトと比較する — 精度の証明と検証の大変さ](https://gcpro.y42u.net/2026/07/08/gsi-comparison-all-test-points/)
- [CCQ（座標変換クオリティー）とは — 4 隅がそろう地点は GSI 一致、欠ける地点は要注意](https://gcpro.y42u.net/2026/06/19/ccq-coordinate-conversion-quality/)
